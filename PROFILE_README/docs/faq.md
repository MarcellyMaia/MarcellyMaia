# Profile FAQ

## Why are some details placeholders?

The profile is designed to be accurate without inventing personal details. Replace every `YOUR_*` value with your actual username, email, and LinkedIn address before publishing.

## Where should I add dashboard images?

Store images in `assets/images/` and reference them from the relevant project repository or from this README using a relative path, for example: `assets/images/dashboard-overview.png`.

## Should I publish real company data?

No. Use public, synthetic, or fully anonymized data only, and state the source and assumptions.

## How do GitHub statistics start working?

Replace `YOUR_GITHUB_USERNAME` in the image links. The cards use public GitHub activity and update automatically.
